# Changelog

## Unreleased

## [1.0.4]

### Security

- Harden pnpm installs with a seven-day release age, trust checks, integrity verification and disabled lifecycle scripts. Pin CI actions by commit.
- Repository dependencies, including development tools: 6 critical, 32 high, 23 moderate, 15 low → 0 critical, 0 high, 1 moderate, 1 low.
- Runtime dependencies only: 0 critical, 0 high, 0 moderate, 0 low. Browser/UMD bundles retain unpatched elliptic 6.6.1; TypeDoc retains a deferred minimatch advisory.
- Standalone example dependencies — examples/nodejs: 0 critical, 2 high, 0 moderate, 0 low → 0 critical, 0 high, 0 moderate, 0 low.
- Standalone example dependencies — examples/react: 0 critical, 30 high, 36 moderate, 8 low → 0 critical, 0 high, 1 moderate, 1 low. Elliptic and UUID findings remain.

### Fixed

- Fix React dev-server native canvas dependency leakage by upgrading `@gamechanger-finance/gc` to 1.2.6 and selecting its browser entry explicitly. Add a Jest dev-optimizer and browser URL-encoding regression test; retain a release-age exception restricted to GC 1.2.6.

- Add a packed three-node transaction/signature exchange across CommonJS, ESM and a real browser, with independent signers and a local relay; cover a three-transaction broadcast with five signatures per signer node per transaction.

- Correct README path arrays, callback syntax, transaction arguments and missing-result handling.

- Correct the TypeScript entry to `dist/types/index.d.ts` and supply its Node declaration dependency.
- Preserve the existing public type contract across the compiler upgrade, including explicit undefined values in optional properties and the Buffer return type.
- Restrict build cleanup to allowlisted output and move test storage into disposable directories. Remove consumer Husky installation hooks.

### Changed

- Run cleanup, packed-consumer, API compatibility and browser/multi-node tests through the existing Jest suite and default `pnpm test` command.

- Migrate the package and both standalone examples to pnpm 11.25.0 with canonical lockfiles.
- Upgrade TypeScript to 6.0.3 and Gun to 0.2020.1241; retain the existing runtime targets, exports, deep imports, CJS/ESM/UMD layout and UMD global.
- Upgrade Jest/ts-jest/types, compatible TypeDoc/ESLint tooling, and the React example’s Vite/polyfill stack. Add packed-consumer, API-contract, old-compiler, browser and cleanup checks.
- Add self-contained maintenance instructions and gate automated tag publication on validation. Correct license metadata to MIT.
